- Suite aplikasi: 107 tes lulus setelah penambahan Commix, termasuk runner palsu yang memverifikasi persistensi temuan positif dan status FAILED untuk laporan time-limit.
- Setelah memperketat hasil negatif Commix: 11 tes active-testing dan endpoint-workflow lulus.

- Renderer dengan IPC mock: SQLmap, Commix, endpoint test dan linked retest lulus; tidak ada page error. Screenshot tersedia di `active-testing-evidence` dan `endpoint-workflow-evidence`.
- WhatWeb 0.6.4 benar-benar berjalan terhadap server HTTP loopback statis dan menghasilkan JSON HTTP 200 yang sesuai target.
- Installer Commix benar-benar melakukan fetch commit, memeriksa HEAD/versi, memasang dependency Windows, dan menyimpan konfigurasi. Versi terpasang `v4.2.dev229`.
- Commix runtime mengirim 7 request ke fixture loopback statis, tanpa evaluasi command pada server. Uji ini membuktikan startup/HTTP/report plumbing, bukan tingkat akurasi deteksi kerentanan nyata.
- Nikto image mengeluarkan `Nikto 2.5.0 (LW 2.5)` saat pemeriksaan versi lokal.
- Instalasi Nikto melalui modul installer aplikasi berhasil: pull digest, pemeriksaan versi tanpa jaringan container, dan aktivasi settings.
- Suite lengkap dijalankan kembali setelah perubahan final: 107/107 lulus. TypeScript dan ESLint tidak menghasilkan error.

## Masalah yang ditemukan dan ditangani

1. Updater WhatWeb mengarah ke paket pip: jalur keliru dihapus, dengan petunjuk runtime Ruby resmi. Instalasi ulang WhatWeb masih manual.
2. Commix di Windows gagal karena readline belum ada walaupun version check sukses: installer memasang pyreadline3 3.5.6.
3. Commix dapat menulis `completed` pada early exit batas waktu internal Windows. Adapter menggunakan deadline runner dan menolak laporan kosong tanpa bukti negatif akhir.
4. EXE portable lama sedang berjalan dan mengunci file: rilis baru disimpan di folder tanggal, tanpa menghentikan aplikasi pengguna.

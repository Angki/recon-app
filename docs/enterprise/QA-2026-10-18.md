## 2. Rincian Hasil Pengujian per Fase

### Fase 0 — Baseline & AI Hardening
- **Mock Transport Determinism**: Pengujian AI Service tidak lagi bergantung pada Ollama daemon lokal (`tests/ai-service.test.ts`).
- **Stream Boundary Buffering**: Buffer `processStreamChunks` dan `flushStreamChunks` menangani chunk parsial JSON secara robust pada batas baris baru.
- **Lint & Type Safety**: Membersihkan seluruh pelanggaran ESLint dan TypeScript tanpa menonaktifkan aturan (*no-disable-comments*).

### Fase 1 — Kontrak Assessment, Fingerprint, Runner & Backup
- **Kontrak Kejujuran Scan**: Menghilangkan penilaian A+/Secure palsu pada scan kosong/gagal. Status mencakup `COMPLETED_CLEAN`, `COMPLETED_WITH_FINDINGS`, `PARTIAL_COVERAGE`, `FAILED`, dan `INTERRUPTED`.
- **Finding Fingerprint v2**: Hash deterministik berbasis SHA-256 yang mempertahankan case-sensitivity URL (`/Admin` vs `/admin`), mendukung line-anchor SAST (`#L10`), normalisasi parameter, dan meredaksi token/rahasia dari input hash.
- **Baseline Comparison Engine**: Membedakan `new`, `reopened`, `persistent`, dan `not_reassessed`. Scanner yang tidak dijalankan atau gagal tidak dapat menandai temuan sebagai `resolved`.
- **Runner Idempotency**: State persistence dijaga dengan single-finalization guard untuk mencegah race condition atau emisi status ganda.
- **Database Backup & Retention**: Rolling backup SQLite dengan validasi `PRAGMA integrity_check`, header `SQLite format 3`, dan pemangkasan retensi berbasis usia dan kuota (menjamin backup terbaru tidak pernah terhapus).

### Fase 2 — Target, Request, & Authentication Workspace
- **Target Bertipe**: Validasi skema untuk `web_url`, `api_spec`, `local_source`, dan `container_image`.
- **Request & Auth Workspace**: Konfigurasi header kustom, cookie sesi, query parameter, dan auth profile (Bearer, Basic, API Key).
- **Scope & Safety Guardrails**: Penegakan boundary in-scope/out-of-scope berbasis regex dan pembatas kecepatan (*rate limiting*) untuk mencegah saturasi target.

### Fase 3 — Tool Platform & Automatic Installation
- **ProcessLockManager**: Mencegah overwrite, update, atau penghapusan tool saat proses scanning aktif.
- **StagingInstaller**: Mengunduh aset ke direktori staging `.staging`, memverifikasi digest SHA-256, mencatat file provenance, dan mendukung rollback atomik jika verifikasi gagal.
- **PythonVenvManager**: Dependency CLI Python diisolasi dalam virtual environment per-tool tanpa mencemari global environment OS.
- **ContainerLifecycleManager**: Melacak ID container Docker dan membersihkan orphaned containers secara otomatis pada pembatalan atau penutupan aplikasi.
- **PreflightSmokeEngine**: Mendiagnosis status kesehatan tool secara presisi: `not_installed`, `runtime_missing`, `unsupported_version`, `healthcheck_failed`, atau `ready`.

### Fase 4 — Additional Tools & Active Testing Hardening
- **SSTImap (v1.2.2)**: Integrasi template injection dengan mode verifikasi non-destruktif berbasis aritmatika (`7*7=49`), CWE-1336, dan redaksi secret.
- **jwt_tool (v2.2.8)**: Inspeksi token offline (Medium) dipisahkan dari eksploitasi terverifikasi server (High/Critical, CWE-347), dengan masking ketat `eyJ...[REDACTED_TOKEN]`.
- **Syft (v1.20.0)**: Adapter SBOM untuk audit dependensi direktori lokal dan container image, mengekstraksi PURL, komponen, dan lisensi (CWE-1395).
- **Interactsh (v1.2.2)**: Adapter Out-of-Band (OOB) interaction dengan korelasi korelasi token per-run, redaksi alamat IP remote dan header otorisasi.

### Fase 5 — Analyst UI & Evidence-Grounded AI Copilot
- **6-Stage Assessment Navigation**: Alur kerja analis terstruktur:
  1. `1. Target & Scope`
  2. `2. Requests & Auth`
  3. `3. Engines & Preflight`
  4. `4. Run & Telemetry`
  5. `5. Findings & Evidence`
  6. `6. Retest & Reports`
- **Ring Buffer Telemetry**: Store log di memori dibatasi pada `MAX_SCANNER_LOG_LINES = 1000` baris dan `MAX_RAW_LOG_CHARS = 500,000` karakter dengan indikator pemotongan visual transparan, mencegah kebocoran memori pada pemindaian durasi panjang.
- **Keyboard Accessible Findings Table**: Navigasi keyboard penuh (`Enter`, `Space`, `Tab`), badge confidence, copy hash fingerprint, dan tab Evidence Drawer.
- **Evidence-Grounded AI**: Guardrail prompt injection dengan tag `<untrusted_assessment_data>`, redaksi secret (Bearer, JWT, Cookie, Private Key), grounding sitasi evidence ID, dan persistensi riwayat analisis ke tabel database `ai_analyses`.

### Fase 6 — Release Build & Distribution Verification
- **Packaging Sukses**: `electron-builder` (v26.15.2) mengemas seluruh bundle renderer `dist` dan core Electron `dist-electron` beserta native binding `better-sqlite3` untuk platform Windows x64.

## 5. Persyaratan Sistem & Lingkungan

- **Sistem Operasi**: Windows 10 64-bit / Windows 11 64-bit / Windows Server 2022.
- **Arsitektur**: x86_64 (amd64).
- **RAM**: Minimal 4 GB (disarankan 8 GB atau lebih untuk concurrent active scanners).
- **Penyimpanan**: Minimal 500 MB untuk aplikasi, plus ruang tambahan untuk tool CLI dan log hasil pemindaian di folder `Documents\SecOpsScans`.
- **Prasyarat Eksternal (Opsional untuk tool tertentu)**:
  - **Python 3.10+**: Diperlukan jika menggunakan plugin berbasis Python (SQLmap, Commix, SSTImap, Arjun, Schemathesis).
  - **Docker Desktop**: Diperlukan jika menggunakan scanner berbasis container (Nikto, Syft container mode).
  - **Ollama**: Diperlukan jika menggunakan fitur AI Copilot dengan model offline lokal (Llama 3, Mistral, CodeLlama).
